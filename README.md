# FINUS Lucky Draw Pro 4.0 Mobile

## 手機優化
- 手機版首頁與抽獎流程縮短
- 按鈕高度加大，單手更好按
- 後台分頁固定於上方
- 獎項設定改成手機直向卡片
- 儲存成功顯示提示
- 點按操作後自動收鍵盤
- iPhone Safari 底部安全區最佳化
- 管理後台閒置 30 分鐘自動登出

## 版本管理
後台「備份」頁面提供：
- 檢查新版
- 立即重新載入最新版
- 清除 Service Worker / Cache 後重新載入
- 保留 localStorage 中的獎項設定與統計

注意：「一鍵更新」的前提是新版檔案已經先上傳到 GitHub。它負責讓手機不再卡在舊快取，不會自行把聊天中的檔案寫入 GitHub。

## GitHub 根目錄需要 7 個檔案

- app.css
- app.js
- manifest.json
- sw.js
- version.json
- README.md
